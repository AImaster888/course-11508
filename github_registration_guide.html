GitHub 完整註冊、建庫 Commit 與 2FA 實戰手冊

依據實機操作流程依序編排，涵蓋：Google 極速註冊、信箱手動註冊、建立首個儲存庫、線上 Commit 檔案、以及必備的 2FA 雙因素身份驗證！

⚡

🚀 【強烈推薦】有 Google 帳號？直接點「Continue with Google」最快！

如果您平時有使用 Google 帳號（Gmail），在註冊時強烈建議直接選擇「Continue with Google」！
👉 優點：無需手動輸入信箱、不用記額外密碼、不用經歷繁瑣驗證，一秒快速完成帳號綁定與授權，最省時省力！

第一階段：GitHub 帳號註冊流程

註冊帳號
1
打開 GitHub 官網並點擊 Sign in (登入)
約 30 秒
打開瀏覽器進入 github.com，點擊右上角紅圈標示的「Sign in」按鈕。
github.comGitHub 官方網站首頁
Sign in登入（右上角按鈕）
https://github.com
2
選擇 Google 極速登入 或 點擊 Create an account 建立帳號
約 20 秒
極速方式：點擊「Continue with Google」，直接用現有 Google 帳號授權最省事。
手動註冊：點擊最下方紅圈處「New to GitHub? Create an account」進入手動表單。
Continue with Google使用 Google 帳號繼續（推薦最快）
New to GitHub?第一次使用 GitHub？
Create an account建立新帳號
https://github.com/login
3
填寫基本資料 ＆ 解決帳號名稱重複問題 (Username Available)
約 1 分鐘
Email：輸入電子信箱 ➔ 右側出現綠勾。
Password：輸入 8 碼以上（含英數）密碼 ➔ 出現綠勾。
⚠️ 重複名稱避坑技巧：
若 Username 輸入常見名稱（如 your.name）出現紅字 "Username is not available"，代表該名稱已被註冊！
👉 解法（示範範例）：可在名稱後面加上自訂後綴或數字（例如 yourname-2026 或 yourname-dev），右側就會出現綠色勾勾 (✔ Available)！
Country/Region：選擇 Taiwan。
確認全部勾選後，點擊下方綠色大按鈕「Create account >」。
https://github.com/signup
4
收信獲取驗證碼並填入 8 位數代碼
約 1 分鐘
網頁畫面：提示 Confirm your email address - We have sent a code to your email，並呈現 8 個輸入框。
信箱收信：打開信箱收到主旨為「🚀 Your GitHub launch code」的郵件，複製紅圈中的 8 位數驗證碼（如 12345678）並填回網頁。
Confirm your email確認您的電子郵件地址
Your GitHub launch code您的 GitHub 啟用發射代碼（信件標題）
Resend the code沒收到信？點此重新發送
https://github.com/signup/verify

第二階段：建立第一個儲存庫 (Repository)

建立專案
5
在 Dashboard 首頁點擊 Create repository 建立專案
約 30 秒
登入進入 GitHub Dashboard（儀表板首頁），左側會看到「Create your first project」。
點擊綠色的「Create repository」按鈕開始建立新儲存庫。
Dashboard儀表板 / 首頁
Create repository建立儲存庫（專案程式碼空間）
https://github.com/dashboard
6
命名儲存庫 helloworld ＆ 設定 Public 公開權限
約 30 秒
Repository name：輸入 helloworld ➔ 下方顯示 ✔ helloworld is available.。
Choose visibility：選擇「Public（公開，全世界皆可查看）」或「Private（私人）」。
點擊右下角綠色「Create repository」按鈕確認建立！
https://github.com/new

第三階段：線上建立檔案並完成第一次 Commit

首次提交
7
在專案頁點擊 creating a new file 線上新增檔案
約 20 秒
儲存庫建立完成後，在 Quick setup 說明區塊中，點擊紅圈處的藍色連結「creating a new file」。
Quick setup快速設定指引
creating a new file建立新檔案（直接在瀏覽器線上編輯）
https://github.com/your-username/helloworld
8
輸入檔名 index.html 內容 hello world 並 Commit changes
約 40 秒
線上編輯：檔名欄位輸入 index.html，下方編輯區輸入 hello world ➔ 點右上角「Commit changes...」。
提交紀錄：彈出視窗內確認 Commit message（例如 Add hello world message to index.html）➔ 點綠色「Commit changes」。
🎉 發布成功： 專案首頁已成功顯示 index.html 與 1 Commit 提交紀錄！您已正式完成 GitHub 第一次發布！
https://github.com/your-username/helloworld/new/main
第四階段：啟用 2FA 雙因素身份驗證 (Two-Factor Authentication)

💡 為什麼必須開？ GitHub 官方為了資安防護，已強制要求所有活躍用戶開啟 2FA（雙重驗證）。未開啟未來可能會被限制推送程式碼！

🎒 開始前，請先在手機上裝好「驗證器 App」
2FA 的 6 位數動態碼是由手機 App 產生的，GitHub 網頁不會給你，也不會用簡訊寄給你。 沒先裝就按下 Enable，會直接卡在下面第 4 步的掃 QR Code（QR Code 有時效，逾時得整個重來）。
👉 iPhone：App Store 搜尋「Google Authenticator」； Android：Google Play 搜尋同一個名字。免費、約 1 分鐘裝好， 用 Microsoft Authenticator 或 1Password 也可以。
⚠️ 裝好之後不要隨便刪除、換手機前要先轉移——以後每次在新裝置登入 GitHub， 都得打開這支 App 抄一次 6 位數。
1
進入設定 (Settings)：
在 GitHub 任何頁面點擊右上角個人圓形頭像 ➔ 點選下拉選單中的「Settings（設定）」。
2
密碼與身份驗證：
在左側側邊欄點選「Password and authentication（密碼和身份驗證）」。
3
啟用雙因素認證：
找到 Two-factor authentication 區塊，點擊綠色按鈕「Enable two-factor authentication（啟用雙因素身份驗證）」。
4
手機 App 掃描 QR 碼：
使用手機打開驗證器 App（推薦免費的 Google Authenticator 或 Microsoft Authenticator），點選掃描 QR 碼功能對準螢幕上的 QR Code。
5
輸入 6 位數驗證碼：
把手機 App 上產生的 6 位數動態代碼 輸入至 GitHub 網頁下方以完成綁定確認。
🚨 【最重要一步】下載並妥善保存「Recovery Codes (復原代碼)」：
綁定完成後，系統會提供一組 16 個復原備用代碼 (Recovery Codes)。
請務必點擊「Download」下載文字檔，或複製存放在安全的地方（如密碼管理器/雲端筆記）！
👉 如果未來手機遺失、換新手機或驗證器被刪除，這組復原代碼是您唯一能登入救回 GitHub 帳號的鑰匙！
